how it thinks · 计算方法

每一个数字，都有来路。

诊断不是拍脑袋的结论，灌溉不是凭感觉的估算。四项赋分、两套定额、一条开灌时间线，都能回看到参数与公式。

01

赋分透明

土壤相对含水量、生育期敏感度、近 7 日有效降雨与未来 7 日预报逐项赋分，总分与档位可逐条核对。

02

定额可算

净灌水定额、毛灌水定额、全地块总水量与可维持天数，全部由田间持水量、湿润层深度与灌溉效率算出。

03

离线可用

不加载 CDN、不请求外部接口、不依赖在线字体与图片。单个 HTML 文件，断网也能打开。

六个入口

从一次判断，到一张能带下地的计划卡。

本步骤已开放参数与规则库，并提供预设地块只读预览；旱情诊断、灌溉决策、节水对比与计划卡将按后续步骤逐步开放。

使用边界

参数为教学常用值，实际生产以当地农技站与墒情监测为准，本工具不替代田间实测。

本工具以浏览器本地运行，不提供云端同步、跨设备同步或服务器备份。本步骤不收集、不上传任何数据，也不保存输入。

module 02 · 灌溉决策

灌溉决策

按计划湿润层深度、田间持水量与当前含水量计算净灌水定额，再按灌溉方式效率折算毛定额与全地块总水量，同时给出可供水量、可维持天数与最迟开灌日。

决策输入

作物、土壤与方式参数自动带入，带 * 为必填。

module 03 · 节水对比

节水对比

复用最近一次灌溉决策的净需求与地块面积，在同一灌水次数下并排比较畦灌、喷灌、滴灌的毛定额、全地块单次总水量与全季总水量。

等待决策

还没有可对比的决策结果

节水对比复用灌溉决策的同一净需求与地块面积。请先在灌溉决策完成一次计算，再回到这里比较三种方式。

三种方式并排对比

同一净需求、同一面积、同一灌水次数；毛定额按各方式 η 只折算一次。

依据：content.md 第七节
次

计算口径

毛定额 = 净定额 ÷ η；1 mm 水层 = 2/3 m³/亩；全地块单次总水量 = 毛定额（m³/亩）× 面积；全季总水量 = 单次总水量 × 灌水次数。

全季节水按未舍入中间值计算。若先把单次全地块节水量舍入到一位小数再乘次数（content.md 第七节示例按此口径得到 1120.2），属于提前舍入，与步骤 3 的精度要求冲突；本工具不采用该做法。

计划卡与输入参数仅保存在当前浏览器/设备，不代表云端备份；清除浏览器数据后可能丢失。
